# OpenCV build and packaging script for Debian/Ubuntu

Working with up to date version of OpenCV when using Debian or Ubuntu, both commonly used as basis for (docker) containers or VMs/cloud instances, is a bit tricky. This script provides an easy to use build instruction to create a (system-wide) `.deb` package suitable for the OS it was build with.

## Features

- all CUDA features are enabled (CUDA 13.x, GPU architectures 7.5 (Turing) up to 12.1 (Blackwell) plus PTX for newer GPUs)
- only non-free features are deactivated (`-DOPENCV_ENABLE_NONFREE=OFF`)
- GAPI support (C++ and Python) is enabled
- BLAS/LAPACK through Intel MKL (linked statically) or OpenBLAS
- optional: CPU-only build (package `opencv-cpu`), Java bindings, examples, HTML documentation
- the package's dependencies follow the selected options (shared library dependencies are generated by `dh_shlibdeps`)

## Instructions

### Docker

Builds the package in a clean container for the selected OS. Requires Docker with BuildKit (default since Docker 23); no GPU is needed to build.

```bash
./docker_build.sh --os ubuntu2404 --cuda-version 13.4
./docker_build.sh --os debian-trixie --cuda-version 13.3 --opencv-version 4.14
./docker_build.sh --os ubuntu2604 --with-cuda off
./docker_build.sh --os ubuntu2404 --cuda-version 13.4 --with-java on --with-examples on --with-docs on
./docker_build.sh --os ubuntu2404 --with-cuda off --use-mkl off
```

| option             | values                                                  | default                |
|--------------------|---------------------------------------------------------|------------------------|
| `--os`             | `ubuntu2404`, `ubuntu2604`, `debian-trixie`             | required               |
| `--with-cuda`      | `on`, `off`                                             | `on`                   |
| `--cuda-version`   | `13.3`, `13.4` (from NVIDIA's compute repo)             | required if CUDA is on |
| `--opencv-version` | `5.0.0`, `4.14.0`                                       | `5.0.0`                |
| `--use-mkl`        | `on` (Intel MKL, linked statically), `off` (OpenBLAS)   | `on`                   |
| `--with-java`      | `on`, `off`                                             | `off`                  |
| `--with-python`    | `on`, `off`                                             | `on`                   |
| `--with-examples`  | `on`, `off`                                             | `off`                  |
| `--with-docs`      | `on`, `off`                                             | `off`                  |
| `--dry-run`        | print the `docker build` command only                   |                        |

Switches also accept `true`/`false`.

- Examples: the compiled examples are installed to `/usr/lib/opencv<major>/examples/<category>/example_*`, the C++ (and, with Python, the Python) sample sources and sample data to `/usr/share/opencv<major>/samples/`.
- Documentation: the Doxygen HTML documentation is installed to `/usr/share/doc/opencv<major>/html/`. Building it adds considerable build time and package size.
- Java: the bindings are compiled for the default JDK of the selected OS (21 on Ubuntu 24.04 and Debian trixie, 25 on Ubuntu 26.04), and the package depends on a matching Java runtime.

The package and the full build log (`build.log`) are written to `./output/<variant>/`, where the variant is `<os>_opencv-<version>_<cuda-<version>|cpu>` plus a suffix for each non-default option (`_openblas`, `_java`, `_nopython`, `_examples`, `_docs`); the console output (build progress, or the end of the build log if it fails) is also saved to `./output/<variant>.log`. Install the package with `# apt install ./output/<variant>/opencv-cuda_x.x.x-x_amd64.deb`, so that its dependencies are installed as well. For CUDA builds NVIDIA's CUDA repository has to be configured on the target system so the CUDA and cuDNN dependencies can be resolved, and the NVIDIA driver has to be installed (or, in containers, provided by the NVIDIA container toolkit) - the package does not depend on a driver version.

A full build takes several hours and uses all CPU cores; nvcc needs a lot of RAM per parallel job.

### Native

1. clone repository
2. install the build dependencies listed in `debian/control` and, for CUDA builds, `cuda-nvcc-13-x`, `cuda-libraries-dev-13-x` and `libcudnn9-dev-cuda-13` from NVIDIA's repository
3. execute `./build_package.sh --cuda-version 13.4` (see `./build_package.sh --help` for all options - the same switches as above, without `--os`)
4. install `./build/opencv-cuda_x.x.x-x_amd64.deb` (`# apt install ./filename`)
5. remove build folder (you may want to keep a backup of the `.deb` file built)
